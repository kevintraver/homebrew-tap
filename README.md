# kevintraver/homebrew-tap

Homebrew casks for Kevin Traver's Mac apps.

```sh
brew install --cask kevintraver/tap/stop-typing-app
```

| Cask | App |
|---|---|
| `stop-typing-app` | [Stop Typing App](https://github.com/kevintraver/stop-typing-app): nudges you to dictate instead of typing out paragraphs |
